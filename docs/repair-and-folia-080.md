# 5.4.0 修复与 Folia 0.8.0 升级

## 实现

- 歌词输入、客户端头和内部上下文有数量及长度限制。只有 HIT 内容校验失败才清理完整 cachePath；网络错误、输入错误和取消不清理同曲目缓存。
- IPv6 按 /64 归一化，反馈和登录先做原生入口限流；反馈新提交保留每分钟五次的 D1 业务配额，登录另加每分钟六十次的全局上限。限流命名空间、过期清理索引和规则索引已加入部署配置与迁移。
- 上游请求共享五个传输槽位及四十次请求预算，逐字阶段最多二十八次。等待计入阶段预算，单次超时从取得槽位后开始；成功的 QQ、网易云和酷狗搜索/响应在同轮复用，真实上游请求数不包含复用事件。正文、解压和响应快照占用均有上限。
- 修复 Spotify 内部时长单位、LRCLIB 错歌候选、播放跳转事件、无上下文曲目、暂停轮询、弹簧休眠、滚动状态与偏移、LRC 边界及重复实体解码。
- 本地歌词先显示再检查规则；迟到的规则不能覆盖新曲目。Apple 匹配与首轮请求并行，已有元数据可直接使用；逐行/纯文本可先显示，再用独立 Apple 查询提高质量。
- 字体后台加载、DOM 观察合并过滤、缓存分批清理、请求失败释放与 UUID 无集合化。主包动态背景使用原生 WebGL，保持现有着色器效果，隐藏/离屏暂停，跨域失败使用内置封面。
- 主包和全屏包使用静态资源路径、完整 SHA-256 和持久 Cache Storage。后续大包由 CI 发布到 releases 分支，主分支仅更新稳定入口和描述；历史大包保留，不重写历史。

## Folia

固定上游 v0.8.0，提交 `3b91924f1e2da7b7f8f9cf1e0cd0b25d4a789e6d`。现有十三种模式升级，增加 Nebbia、Hanabi、Machi、Metaphor，共十七种，继续排除 Fume。模式与背景调参复用上游校验并保存在 Reborn 名下；原有模式、字号、字幕偏好和歌词偏移保留。

在线版首次进入全屏才加载 Folia，首次使用 Nebbia 才获取经过哈希校验的笔顺资源。离线版内嵌全部资源。版权和笔顺许可随产物分发。音频分轨、独立音源、模组市场、视频导出、URL 背景和上游自定义素材库不在本集成内；缺失的鼓点/人声分轨返回不可用，歌词与普通视觉效果继续运行。

## 发布与回退

发布前使用新的 CI 流程或 `node Extension/Tasks/PublishRelease.mjs`。保留现有鉴权兼容性验证与 D1 UUID 配置要求；入口限流绑定由新的 wrangler 配置提供。缓存内容版本为服务端 6、客户端 15。旧歌词内容逐步失效，不更改用户偏移。

流程先部署新服务和新资源、保持旧指针，验证后上传 releases 分支的哈希资源并验证 CDN，再切换生产指针，最后更新分支指针和 Marketplace 入口。切换验证失败恢复旧指针；数据库索引迁移是追加式的，回退不删除反馈、规则或历史诊断。
